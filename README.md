Mô tả hệ thống



Hệ thống quản lý nhân sự được xây dựng và triển khai trên nền tảng điện toán đám mây.



Hệ thống cho phép người dùng xem danh sách nhân viên, xem thông tin chi tiết, thêm nhân viên mới, tìm kiếm theo mã nhân viên hoặc họ tên, cập nhật và xóa hồ sơ nhân viên.



Dữ liệu được lưu trữ trên MongoDB Atlas. Frontend sử dụng REST API để giao tiếp với Backend.
